# LLMAO101n: Let's Build a Storyteller

> **An AI-generated course based on Andrej Karpathy's teachings**

This repository contains a 97,000-word written tutorial covering every step in the curriculum—from bigram models to multimodal transformers—generated entirely by an automated knowledge extraction pipeline.

## What Is This?

[Eureka Labs](https://eurekalabs.ai) announced LLM101n as an AI-native course teaching students to build a storytelling LLM from scratch. The [course roadmap]([https://github.com/karpathy/LLM101n]) has been public since mid-2024, but the full course hasn't shipped yet.

We wanted to see if our prototype system could generate it.

**This tutorial was produced by ingesting ~4 million characters of Andrej Karpathy's public YouTube lectures and Stanford CS course transcripts, then running them through a multi-agent extraction and synthesis pipeline.**

The result is a complete written course covering all 17 planned modules:

1. Bigram Language Model
2. Micrograd
3. N-gram Model  
4. Attention
5. Transformer
6. Tokenization
7. Datasets
8. Optimization
9. Need for Speed I — Device
10. Need for Speed II — Precision
11. Need for Speed III — Distributed
12. Inference I — KV-Cache
13. Inference II — Quantization
14. Deployment
15. Finetuning I — SFT
16. Finetuning II — RL
17. Multimodal

Each module contains multiple lessons with explanations, code examples, common mistakes, success criteria, and practice exercises.

## How It Was Made

This course was generated by **Expert Studio**, a prototype knowledge extraction system built by [Nampara AI](https://x.com/NamparaAI).

The pipeline works in stages:

1. **Librarian** — Ingests and classifies source material
2. **Analyst** — Assesses structure and identifies knowledge gaps  
3. **Architect** — Extracts discrete knowledge units ("axiom cards") with typed semantic relationships
4. **Student** — Validates extracted knowledge through multiple reasoning lenses and generates confidence scores
5. **Ghostwriter** — Synthesizes the validated knowledge into authored curriculum content

The entire pipeline ran locally on a Mac Mini over ~5 hours. Total API cost was approximately $25 (using DeepSeek for early stages, Claude Opus for final synthesis).

**No human editing occurred during generation.** The module list was provided in a single prompt; everything else was automated.

## Why Release This?

Three reasons:

1. **Proof of concept.** Automated knowledge extraction and curriculum synthesis is possible at quality levels that surprised even us. 

2. **Pressure test.** We want people to find the bugs, hallucinations, and gaps we missed. Real-world feedback is the fastest path to improving the system.

3. **Demonstration.** If you're an expert sitting on hours of recorded content, transcripts, or rough notes—and you've been meaning to turn it into a course, book, or knowledge base—this is what's now possible.
